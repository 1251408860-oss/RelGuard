# Reference data

Run `python -m scguard verify-data` to verify `scguard/data/manifest.sha256.json`.

## Layout

| Directory | Contents |
| --- | --- |
| `writer/` | 12 writer models, eight transition records, protocol and comparison results |
| `writer/native/` | Query-used states and saved native O0/O2 outputs |
| `cross_family/` | 12 cross-family models, eight transition records and source-route metadata |
| `cross_family/native/` | States and O0/O2 outputs used by relational requests |
| `cross_family/training/` | Original basis/held-out or comparison-alphabet observations used for candidate fitting |
| `cross_family/guards/` | Final and intermediate systems, C guards, requests and saved compiled outputs |
| `figures/` | Recorded figure values and editable TeX tables |

The training streams are reused from completed executions. They are distinct from the request-reference streams and are not regenerated by the package preparation.

## Binary format

Records are little-endian and packed without padding.

| Record | Python struct | Bytes |
| --- | --- | ---: |
| State: x, configuration, eight entry bytes | `<II8B` | 16 |
| Cross-family output: return word and eight final bytes | `<I8B` | 12 |
| Writer output: signed return and eight final bytes | `<i8B` | 12 |
| Pair request: left state, right state, observer/mask | `<II8BII8BI` | 36 |
| Compiled guard result | `B` | 1 |

Cross-family observer indices 0..4 mean return, first4, last4, buffer8 and full. Writers use a nonzero nine-bit field mask. Guard results are 0 UNKNOWN, 1 SUPPORT and 2 REFUTE.

## Scope

Replay checks saved native/model agreement, compiled-guard answers, intermediate admission, comparison-policy totals and affine certificates. The data preserve failed or incomplete historical outcomes where they explain the study.

The complete historical experiment workspace, raw source-checker archive and upstream source distributions remain in the original project archive. Public source identifiers, assumptions and flags are included for preparing new checks.
